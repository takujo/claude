# ポケモン さんすうマスター

7歳向けの たしざん・ひきざん・かけざん・わりざん 練習アプリ（家庭用・iPad向け）。

## iPadで使う
1. GitHub Pages などで `pokemon-math/` を公開（または iPad にフォルダごとコピー）。
2. Safari で開き、共有ボタン →「ホーム画面に追加」でアプリのように全画面で起動。
3. 記録は端末の localStorage に保存されます（Safariのデータ削除で消えます）。

## 続けたくなる仕掛け
- 毎日のミッション（バトル3回）＋ 連続日数🔥 ＋ スタンプカレンダー
- 正解でワイルドポケモンにダメージ → つかまえて「ずかん」を埋める（54種）
- パートナーが なかよしポイントで進化（ピチュー→ピカチュウ→ライチュウ など）
- ボール／スーパーボールのガチャ、レア・でんせつポケモン
- ★2つ以上で次のレベルが開放（各演算4レベル）。まちがえた問題はその場でもう一度出題
- ヒント（ドット図）、読み上げ、おうちの人向けの成績画面
